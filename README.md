# Mochi & Bơ Studio

Vietnamese public website and local-only video/caption preparation interface.

- Website: https://ttalkkaklab.github.io/mochi-bo-studio/
- Privacy: https://ttalkkaklab.github.io/mochi-bo-studio/privacy.html
- Terms: https://ttalkkaklab.github.io/mochi-bo-studio/terms.html

Static HTML/CSS/JavaScript, hosted on GitHub Pages. No backend, secrets, OAuth callback, analytics or upload service in this repository. The browser preview uses object URLs and never sends selected videos to a server. TikTok integration runs separately on the operator's machine and is currently in sandbox setup.

Run locally: `python3 -m http.server 8766 --bind 127.0.0.1`.
